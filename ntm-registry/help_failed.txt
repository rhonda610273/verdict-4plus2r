============================================================
 系統啟動失敗，原因在上面幾行英文訊息裡。
============================================================

 常見狀況：

  Address already in use / 10048
     連接埠 3001 已被占用。可能你已經開了另一個視窗在跑，
     或別的程式正在用 3001。
     解法：關掉其他視窗再試，或用別的埠啟動：
           start.bat --port 3002

  Permission denied / 10013
     防火牆或防毒軟體擋住了。請資訊室協助放行。

  SyntaxError 或 No module named
     Python 版本太舊，本系統需要 3.8 以上。
     打 python --version 看看版本。

 把上面整個視窗截圖下來，就能拿去問人。
============================================================
