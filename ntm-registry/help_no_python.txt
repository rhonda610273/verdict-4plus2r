============================================================
 這台電腦沒有可用的 Python，系統無法啟動。
============================================================

 注意：Windows 10/11 內建一個「假的」python.exe，
 它只會打開 Microsoft Store，不能真的執行程式。
 所以就算你打 python 有反應，也不代表已經安裝好了。

 請照以下步驟安裝真正的 Python：

   1. 開啟瀏覽器前往   https://www.python.org/downloads/
   2. 點黃色的「Download Python」按鈕
   3. 執行下載的安裝檔
   4. 【最重要的一步】安裝畫面第一頁最下方有一個核取方塊
      「Add python.exe to PATH」，一定要打勾再按下一步
   5. 選 Install Now，等它裝完
   6. 關掉這個視窗，重新雙擊 start.bat

 如果醫院電腦禁止自行安裝軟體，請資訊室協助安裝。
 Python 是免費開源軟體，通常不難通過。

 補充：安裝時若看到「Disable path length limit」也建議點一下。
============================================================
